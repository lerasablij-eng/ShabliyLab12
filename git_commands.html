Create a Repository

From scratch - Create a new local repository

$ git init [project name]

Download from an existing repository

$ git clone my_url

Observe your Repository

  • Список новых или изменённых файлов: git status
  • Показать изменения в файлах, которые ещё не добавлены: git diff
  • Показать изменения в подготовленных файлах: git diff --cached
  • Показать все изменения: git diff HEAD
  • Показать различия между двумя коммитами: git diff commit1 commit2
  • Показать даты изменений и авторов файла: git blame [file]
  • Показать изменения файла в определённом коммите: git show [commit]:[file]
  • Показать историю изменений: git log
  • Показать историю изменений файла или папки: git log -p [file/directory]

Working with Branches

  • Список всех локальных веток: git branch
  • Список локальных и удалённых веток: git branch -av
  • Переключение на другую ветку: git checkout my_branch
  • Создание новой ветки: git branch new_branch
  • Удаление ветки: git branch -d my_branch
  • Объединение двух веток: git checkout branch_b git merge branch_a
  • Создание тега для текущего коммита: git tag my_tag

Make a change

  • Добавить файл для будущего коммита: git add [file]
  • Добавить все изменённые файлы: git add .
  • Сохранить подготовленные изменения: git commit -m "commit message"
  • Добавить и сохранить все отслеживаемые файлы: git commit -am "commit message"
  • Убрать файл из подготовленных, сохранив изменения: git reset [file]
  • Вернуться к последнему коммиту: git reset --hard
